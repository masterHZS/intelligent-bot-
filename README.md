# Intelligent Bot Platform

## 项目简介

本项目面向工业园区、办公楼及仓储环境，构建一套基于 `STM32 + RK3568 + Web` 的智能巡检机器人平台。系统支持设备感知、状态采集、本地边缘处理、云端对接、网页端监控与远程管理，形成从下位机到上位机再到平台侧的闭环控制链路。

本项目核心目标是实现本地服务器与云服务器的实时对接，并围绕智能巡检、状态监控、异常识别和远程运维建立完整的数据通路。

## 核心功能

- 自主巡检与状态采集
- 传感器数据读取与设备联动控制
- 本地服务器与云服务器实时数据同步
- AI 异常识别与告警上报
- 网页端远程监控与设备管理
- 历史记录、任务状态与告警信息展示

## 系统架构

- 下位机：基于 `STM32`，负责传感器接入、底层驱动、运动控制、状态采集与执行控制
- 上位机：基于 `RK3568`，负责边缘计算、设备管理、数据汇聚、AI 推理与通信转发
- 服务端：负责接口服务、数据存储、消息转发、权限管理与远程接入
- Web 端：负责设备状态展示、任务下发、告警查看与运维管理

详细说明见 [docs/system_overview.md](docs/system_overview.md)。

## 技术栈

- Embedded C / STM32 HAL
- UART / I2C / SPI / CAN / TCP / MQTT
- RK3568 Linux 平台开发
- Web 管理后台
- 本地服务器与云平台协同通信
