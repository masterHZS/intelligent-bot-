# 系统总览

## 项目目标

构建一套具备巡检、采集、识别、告警、远程监控能力的智能机器人平台，实现设备端、边缘端、服务端与前端页面的完整打通。

## 功能分层

### 1. 下位机层

- 传感器数据采集
- 电机与执行机构控制
- 外设驱动管理
- 通信协议封装

### 2. 边缘计算层

- 数据汇聚与预处理
- 本地任务调度
- AI 异常识别
- 与云端的数据同步

### 3. 平台服务层

- 接口服务
- 数据库存储
- 消息转发
- 告警记录与日志管理

### 4. 可视化层

- 实时设备状态监控
- 巡检任务展示
- 告警信息查看
- 远程控制与参数配置

## 目标效果

- 数据采集链路稳定
- 本地与云端通信可用
- 巡检状态可追踪
- 异常事件可记录、可上报、可展示
