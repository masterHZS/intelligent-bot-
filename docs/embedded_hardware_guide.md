# 嵌入式硬件需要掌握的内容

## 1. 先建立整体认知

做嵌入式硬件，第一步不是背器件型号，而是先明白一块板子到底由哪些部分组成。一个典型的嵌入式系统通常包括：

- 主控芯片
- 电源部分
- 时钟电路
- 复位电路
- 下载与调试接口
- 存储器
- 传感器与执行器接口
- 通信接口
- 人机交互接口
- 保护与抗干扰电路

你后面学到的所有原理图、PCB、调试、排错，基本都绕不开这几个部分。

---

## 2. 必须掌握的基础电子知识

### 2.1 电压、电流、电阻、功率

这是最基础的四个量。

- 电压：驱动电路工作的“压力”
- 电流：电荷流动的“量”
- 电阻：对电流的阻碍
- 功率：器件消耗或输出的能量速度

常用关系：

```text
U = I × R
P = U × I
```

实际意义：

- 看 LED 限流电阻是否合理
- 看电源是否能带得动负载
- 看芯片引脚是否会过流
- 看稳压器是否会发热

### 2.2 直流、交流、纹波

嵌入式硬件大多数用直流供电，但真实电源并不“绝对纯净”。

- 直流：方向基本不变
- 交流：方向周期变化
- 纹波：直流中夹杂的周期性波动

你要理解：

- 电源不是越高越好，而是要稳定
- 5V、3.3V、1.8V 不能混
- 纹波大，芯片可能复位、通信异常、ADC 漂移

### 2.3 基本元件

要会看和会用：

- 电阻：分压、上拉、下拉、限流、采样
- 电容：滤波、耦合、去耦、储能、定时
- 电感：滤波、升降压电源
- 二极管：整流、防反接、续流
- 三极管 / MOS 管：开关、驱动、功率控制

你至少要知道它们在电路里各自的作用，而不是只会认符号。

---

## 3. 必须看懂的核心电路

### 3.1 电源电路

电源是整个系统的根。

你需要掌握：

- 输入电源范围
- 稳压方式
- 反接保护
- 过流保护
- 上电时序
- 去耦和滤波

常见模块：

- DC-DC 降压
- LDO 线性稳压
- 电源监控芯片
- 电源开关 MOS 管

重点判断：

- 输入压差够不够
- 输出电流够不够
- 发热是否超标
- 负载突变时会不会掉压

### 3.2 时钟电路

主控芯片需要时钟才能工作。

常见时钟源：

- 外部晶振
- 外部有源时钟
- 内部 RC

你要知道：

- 晶振频率决定系统节拍
- 晶振布局不对会起振失败
- 晶振两侧负载电容要匹配
- 时钟不稳会导致串口、USB、CAN、定时器异常

### 3.3 复位电路

复位是让芯片回到初始状态。

要会看：

- 手动复位按键
- 上电复位
- 监控复位芯片

常见问题：

- 复位脚上拉不对
- 复位脉冲宽度不够
- 电源波动导致反复复位

### 3.4 启动配置电路

很多主控芯片有启动模式引脚。

你要知道：

- 什么是上电启动
- 什么是下载模式
- 什么是从 Flash 启动
- 启动脚拉高拉低的意义

这类问题在 STM32、ESP32、部分 Linux SoC 上都很常见。

### 3.5 下载与调试电路

你必须熟悉：

- JTAG
- SWD
- 串口下载
- USB 下载

你至少要知道：

- 哪几个引脚是下载口
- 地线是否共地
- 下载电压是不是匹配
- 调试器是否识别得到芯片

### 3.6 最小系统

一个 MCU 能跑起来的最基本条件：

- 电源正确
- 时钟正常
- 复位正常
- 启动配置正确
- 下载口能连上

这就是“最小系统”。

## 4. 主控芯片要懂什么

主控芯片是嵌入式硬件的核心。

### 4.1 需要看懂的数据手册

重点看这些内容：

- 供电电压范围
- IO 电平标准
- 引脚复用
- 最大灌电流和拉电流
- ADC/DAC 精度
- 定时器、串口、SPI、I2C、CAN 能力
- Flash 和 RAM 容量
- 工作温度范围

### 4.2 IO 口基础

你要懂：

- 输入 / 输出 / 复用
- 推挽 / 开漏
- 上拉 / 下拉
- 高低电平阈值
- IO 最大驱动能力

这直接关系到：

- 能不能直接带 LED
- 能不能直接驱动继电器
- 能不能直接接传感器
- 能不能接 5V 外设

### 4.3 模拟与数字接口的区别

- 数字：高低电平，逻辑判断
- 模拟：连续变化，靠 ADC 读取

你要知道：

- ADC 输入前面通常要滤波
- 模拟地和数字地要处理好
- 高速数字线不要乱穿模拟区

## 5. 常见外围器件

### 5.1 电阻

常见用途：

- 限流
- 分压
- 上拉 / 下拉
- 采样
- 匹配阻抗

要会看：

- 阻值
- 功率
- 精度
- 封装

### 5.2 电容

常见用途：

- 电源去耦
- 滤波
- 定时
- 耦合

你要知道：

- 小电容适合高频去耦
- 大电容适合储能和低频滤波
- 电容离芯片越近越好

### 5.3 二极管

常见用途：

- 防反接
- 续流
- 钳位
- 整流

尤其是驱动继电器、电机时，续流二极管很关键。

### 5.4 三极管与 MOS 管

用途：

- 放大
- 开关
- 驱动负载

你要分清：

- NPN / PNP
- N 沟道 / P 沟道 MOS
- 低端驱动 / 高端驱动

这在驱动电机、蜂鸣器、灯带、继电器时非常常见。

## 6. 常见接口必须会

### 6.1 GPIO

GPIO 是最基础的接口。

会看：

- 输入输出方向
- 高低电平
- 上拉下拉
- 中断触发
- 去抖动

### 6.2 UART 串口

串口是嵌入式里最常用的调试和通信方式之一。

你要懂：

- 波特率
- 数据位
- 停止位
- 校验位
- TX / RX
- 共地

常见问题：

- 波特率不一致
- TX RX 接反
- 电平不兼容
- 地没共好

### 6.3 I2C

I2C 常用来接：

- 温湿度传感器
- OLED
- IMU
- EEPROM

你要懂：

- SCL / SDA
- 上拉电阻
- 地址
- 时钟速率
- ACK / NACK

### 6.4 SPI

SPI 适合速度更快的器件。

你要懂：

- SCLK
- MOSI
- MISO
- CS
- 时钟极性 CPOL
- 时钟相位 CPHA

### 6.5 CAN

CAN 常用于车载、工业控制。

你要知道：

- 差分通信
- 总线终端电阻
- 收发器
- 仲裁机制

### 6.6 ADC

ADC 是把模拟量转成数字量。

你要懂：

- 分辨率
- 采样率
- 参考电压
- 输入阻抗
- 量化误差

### 6.7 PWM

PWM 常用于：

- 调光
- 调速
- 舵机控制
- 蜂鸣器驱动

要理解占空比、频率和输出能力。

## 7. 传感器和执行器

### 7.1 传感器

常见类型：

- 温湿度
- 光照
- 红外
- 超声波
- IMU
- 气体
- 压力
- 电流 / 电压采样

你要知道：

- 它输出的是模拟还是数字
- 供电电压是多少
- 是否要上拉
- 初始化流程是什么
- 数据读取周期是多少

### 7.2 执行器

常见类型：

- 电机
- 舵机
- 继电器
- 蜂鸣器
- 指示灯
- 电磁阀

你要知道：

- 需要多大电流
- 是否需要驱动芯片
- 是否有反向电动势
- 是否要隔离

---

## 8. 电源系统要重点理解

### 8.1 常见供电架构

- 12V 转 5V
- 5V 转 3.3V
- 3.3V 转 1.8V

### 8.2 常见问题

- 上电启动失败
- 电源掉压
- 纹波过大
- 芯片发热
- 负载一接就重启

### 8.3 去耦与滤波

你要知道：

- 每个芯片供电脚附近都要放去耦电容
- 大电流负载旁边要加储能电容
- 模拟电源和数字电源最好分开处理

---

## 9. PCB 设计必须掌握的点

### 9.1 布局

先看功能分区：

- 电源区
- 数字区
- 模拟区
- 高速区
- 接口区

### 9.2 走线

要注意：

- 电源线要足够宽
- 高速信号要短
- 时钟线尽量短
- 模拟线远离干扰源
- 差分线尽量成对

### 9.3 地

地不是“随便铺就行”。

你要懂：

- 地回流路径
- 数字地和模拟地处理
- 大电流回路不要乱走
- 地弹噪声会影响系统稳定性

### 9.4 EMI / EMC

要理解：

- 为什么有些板子一上电就乱
- 为什么靠近电机时通信会错
- 为什么长线会引入干扰

常见手段：

- 加滤波
- 加 TVS
- 加磁珠
- 合理布线
- 必要时做隔离

---

## 10. 调试能力非常关键

### 10.1 常用工具

- 万用表
- 示波器
- 逻辑分析仪
- 可调电源
- 焊台 / 热风枪
- 下载器 / 调试器

### 10.2 调试顺序

建议顺序：

1. 看电源是否正常
2. 看时钟是否起振
3. 看复位是否正确
4. 看下载口是否能识别
5. 看串口是否有输出
6. 看外设是否响应
7. 看通信是否稳定

### 10.3 常见故障判断

- 板子不亮：先看电源
- 下载失败：看供电、复位、BOOT、调试线
- 串口乱码：看波特率和时钟
- 外设没反应：看地址、上拉、电平、供电
- 负载带不动：看驱动能力和功率

## 11. 可靠性与保护

嵌入式硬件不是“点亮就行”，而是要稳定。

你要懂：

- 过压保护
- 过流保护
- 反接保护
- ESD 防护
- TVS 管
- 保险丝 / 自恢复保险丝
- 隔离方案

这些东西在真实产品里非常重要。

## 12. 嵌入式硬件学习路线

### 第一阶段：基础

- 学会看原理图
- 学会认识元器件
- 理解电源、电阻、电容、二极管、三极管
- 掌握 GPIO、串口、I2C、SPI 基础

### 第二阶段：能看懂板子

- 能看懂 MCU 最小系统
- 能看懂传感器接法
- 能看懂电源和复位
- 能看懂下载调试接口

### 第三阶段：能独立排错

- 会用万用表测电压
- 会用示波器看波形
- 会判断串口、I2C、SPI 问题
- 会处理板子不上电、通信失败、干扰等问题

### 第四阶段：接近产品

- 会做保护
- 会做 EMC 考虑
- 会做功耗优化
- 会做量产可维护设计

---

## 13. 建议你真正记住的重点

如果只记一版最重要的内容，可以记下面这些：

- 电源是第一位的
- 时钟和复位决定芯片能不能跑
- 下载口和调试口决定你能不能救板子
- UART / I2C / SPI 是最常见的接口
- 去耦、滤波、上拉、下拉不是装饰，是稳定性的基础
- PCB 不是把线连起来就行，布局和地线很重要
- 调试能力比死记器件更重要
