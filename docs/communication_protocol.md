# 通信协议说明

## 通信链路

### 下位机到上位机

- 推荐接口：`UART / RS485 / CAN`
- 数据内容：设备 ID、时间戳、传感器值、执行状态、错误码

### 上位机到服务端

- 推荐方式：`TCP / HTTP / MQTT`
- 数据内容：设备状态、任务结果、图像识别结果、告警信息

## 数据包建议字段

```text
Header | DeviceID | MsgType | Length | Payload | CRC
```

## 常见消息类型

- `0x01` 状态上报
- `0x02` 传感器数据
- `0x03` 控制指令
- `0x04` 告警信息
- `0x05` 心跳包

## 设计建议

- 所有消息带时间戳
- 控制指令支持应答机制
- 异常消息单独记录
- 网络中断时支持本地缓存与重传
